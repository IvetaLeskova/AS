# Task Manager [Software Architecture]

University project for the **Software Architecture** course at FIIT STU (2026/2027).

**Authors:** Iveta Lešková, Richard Zahoranský

## Project 1 – Architecture Comparison
Comparison of three software architectures using the same Task Manager application:
- Layered Architecture
- Modular Monolith
- Hexagonal Architecture

The goal is to evaluate their structure, modifiability, testability, and maintainability.

## Project 2 – Software Product Line
Development of a configurable Task Manager using a feature model and reusable components.

The goal is to demonstrate feature variability, code reuse, and different product configurations.

## Technologies
Python, FastAPI, SQLite, SQLAlchemy, pytest.
